# FilmTrack — учебный многостраничный сайт

FilmTrack — личная кинотека для поиска фильмов и сериалов, подбора по настроению и ведения списков просмотров.

## Страницы сайта

- `index.html` — главная страница.
- `catalog.html` — каталог с поиском, фильтрами по типу и жанру, сортировкой.
- `podbor.html` — подборка по настроению и текстовому описанию.
- `my-list.html` — личные списки: «Хочу посмотреть», «Смотрю», «Просмотрено».

## Файлы проекта

- `style.css` — стили и адаптивная вёрстка.
- `data.js` — демонстрационная база фильмов.
- `app.js` — общая логика сайта: фильтры, списки, рекомендации, карточки, регистрация и навигация.
- HTML-файлы — отдельные страницы сайта.

## Как запустить

1. Распакуй архив.
2. Открой папку `FilmTrack` в Visual Studio Code.
3. Открой `index.html` в браузере. Можно использовать расширение Live Server, если оно установлено.
4. Для просмотра других разделов нажимай пункты верхнего меню.

Node.js для этой версии не требуется.

## Что уже работает

- Переходы между отдельными HTML-страницами.
- Поиск по названию на русском и английском.
- Фильтры по типу и жанру.
- Сортировка каталога.
- Карточки с краткой информацией и окном подробностей.
- Добавление фильмов в три списка.
- Сохранение списков в localStorage текущего браузера.
- Подбор вариантов по выбранному настроению и словам в запросе.
- Демонстрационная форма регистрации и входа.
- Адаптация под телефоны и компьютеры.

## Честные ограничения текущей версии

Это фронтенд-прототип, а не готовый онлайн-сервис.

- Каталог содержит демонстрационные данные, а не полную базу кино.
- Обложки сделаны средствами CSS, чтобы проект запускался без внешних изображений.
- Подборка использует простые правила и ключевые слова. Настоящий ИИ пока не подключён.
- Регистрация демонстрационная: данные сохраняются в localStorage браузера. Пароли не защищены — не используй настоящие пароли.
- Списки и аккаунты хранятся только в текущем браузере и не синхронизируются автоматически между компьютерами.
- Для настоящей авторизации, синхронизации между устройствами и подключения TMDB/ИИ API понадобится серверная часть, база данных и безопасное хранение секретных ключей.
